## 💡 关键发现

### 1. 训练周期的影响

**40 epochs → 50 epochs**:
- 整体改进: +0.02%
- Task 2改进: +0.15% (最显著)
- Task 3-5改进: +0.02-0.05%

**结论**: 50 epochs对Task 2帮助最大,边际收益递减

---

### 2. 原型细化的重要性

**迭代次数影响**:
- 8次: 87.56% (40 Epochs)
- 10次: 87.45% (Stable Config)
- 12次: 87.58% (50 Epochs)

**Momentum影响**:
- 0.8: 87.56%
- 0.82: 87.45%
- 0.85: 87.58%

**对比权重影响**:
- 0.5: 87.56%
- 0.6: 87.45%
- 0.8: 87.58%

**结论**: 12次迭代 + 0.85 momentum + 0.8对比权重是最佳组合

---

### 3. 融合策略的影响

**KNOTS vs OPCM**:
- KNOTS (50 Epochs): 87.58%
- OPCM: 86.02%
- 差异: **-1.56%**

**OPCM失败原因**:
- Task 3表现最好 (90.00%)
- Task 4-5严重退化
- 正交投影过度限制参数空间

**结论**: KNOTS融合策略更稳定可靠
